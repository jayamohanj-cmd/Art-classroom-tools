# Tools for the Art Room

One page that links free browser tools for art students, built in an art classroom. No login, nothing to install.

**Open it:** https://jayamohanj-cmd.github.io/Tools-for-the-artroom/

| Tool | For | Open | Code |
|---|---|---|---|
| Idea Generator | When you're stuck at the start of a project | [Open](https://jayamohanj-cmd.github.io/Idea-Generator/) | [Code](https://github.com/jayamohanj-cmd/Idea-Generator) |
| Manual Mode Simulator | Practising aperture, shutter and ISO before using a real camera | [Open](https://jayamohanj-cmd.github.io/Manual-Mode/) | [Code](https://github.com/jayamohanj-cmd/Manual-Mode) |
| Daily Drawing Warm-Up | The first five minutes of class | [Open](https://jayamohanj-cmd.github.io/Warmup-Drawings/) | [Code](https://github.com/jayamohanj-cmd/Warmup-Drawings) |
| Spray Paint Portraits | Turning a photo into stencils you can cut | [Open](https://jayamohanj-cmd.github.io/Stencil-Portraits-/) | [Code](https://github.com/jayamohanj-cmd/Stencil-Portraits-) |

Coming next: a new media art web tool.

Feel free to use these with your students, or take the code and develop the ideas further.
